TREE PLANTING - Firebase Auth (Java)
1. Open the TreePlanting folder in Android Studio.
2. Firebase Console > add Android app, package: com.example.treeplanting
3. Download google-services.json -> put in app/ folder.
4. Authentication > Sign-in method > Email/Password > Enable.
5. Sync Gradle and run.
Optional: replace res/drawable/ic_logo.xml usage with your own img.png
(copy to res/drawable and change android:src in activity_main.xml).
